Regenerate the frontend TypeScript API client for SmartTraffic AI.

The client in `frontend/src/client/` is fully auto-generated by `@hey-api/openapi-ts` — never edit it manually.

**Steps to regenerate:**

1. Export the OpenAPI schema from the FastAPI app (the backend does NOT need to be running — it imports directly):
   ```
   cd backend && uv run python -c "import app.main; import json; print(json.dumps(app.main.app.openapi()))" > ../openapi.json
   cd ..
   mv openapi.json frontend/
   ```

2. Generate the typed client:
   ```
   bun run --filter frontend generate-client
   ```

3. Auto-fix any lint issues in the generated files:
   ```
   bun run --filter frontend lint
   ```

Or run all three steps at once using the project script:
```
bash scripts/generate-client.sh
```

**After regeneration:**
- Check `frontend/src/client/sdk.gen.ts` for the updated service methods
- Check `frontend/src/client/types.gen.ts` for updated request/response types
- If any frontend component imports broke (type errors), fix them now before committing

The pre-commit hook `generate-frontend-sdk` runs this automatically when backend files change during a commit.
